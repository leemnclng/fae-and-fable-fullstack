# App Context

Living product and engineering notes for Fae&Fable, following the Print-MS documentation pattern.

## Files

- [functionality-map.md](functionality-map.md): current pages, features, and retention behavior.
- [progress-log.md](progress-log.md): completed work and active progress.
- [change-log.md](change-log.md): notable changes grouped by date.
- [issues-log.md](issues-log.md): known limitations, open questions, and follow-up work.
- [decisions.md](decisions.md): implementation choices and their implications.

## Update Habit

When making a meaningful app change:

1. Add a short dated entry to `progress-log.md`.
2. Record user-facing changes in `change-log.md`.
3. Update `functionality-map.md` when behavior changes.
4. Add unresolved problems to `issues-log.md`, and mark resolved items with a date.
5. Capture important tradeoffs in `decisions.md`.

Use newest-first entries and distinguish implementation status from verified test results. See [development.md](../development.md) for setup and check commands.
